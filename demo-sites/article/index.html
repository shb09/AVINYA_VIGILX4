The quiet architecture of the modern web

Pages, scripts and machine readers now share one surface. The interesting decisions are hiding in the seams between them.

By J. R. Halden · 8 min read

Twenty years ago a webpage was a document. Today it is closer to a surface that speaks back: it reads you, it reacts, it writes itself around you. The shift happened quietly, inside fetch calls and event listeners, but it changed who controls the experience.

One surface, many readers

A single page now serves at least three audiences at once. A human reads it as prose. A script reads it as data. And increasingly, an agent reads it as an interface it can act on.

Each reader trusts the page differently. Humans have instincts about a layout. Scripts have contracts. Agents — if you build them carelessly — simply believe whatever the page tells them to do.

“Trust is not a property of a page. It is a property of a decision.”

The difference between content and instruction

Most pages contain both. An article contains content about the world; a button contains an instruction to do one thing. The trouble begins the moment a page mixes the two — when something that looks like content quietly asks the reader to act.

For a human this is an inconvenience, a dark pattern, a scam. For an autonomous agent it is a control channel: a way to steer an actor with more power than the page should ever have.

Reading ahead

In the final part of this piece we look at what changes when a machine, not a person, is the one who decides whether to act on a page's request — and why the boundary between “observe” and “execute” is the most heavily defended seam on the modern web.

The agent proposes. The boundary decides. The browser executes.
